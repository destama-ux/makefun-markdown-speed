A hand-written, dependency-free Markdown renderer in JavaScript. Its parse(markdown) returns HTML byte-identical to marked 18.1.3 with default options, at roughly 1.5× the speed. Written from scratch by an AI agent for make.fun's "Make Markdown rendering faster" bounty.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
